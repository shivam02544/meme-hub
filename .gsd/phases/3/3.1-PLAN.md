# Plan 3.1: Database Schema Update & File Upload Backend

## Objective
Extend the Memes table to support multiple meme types (text, image, video). Install `multer` for file uploads and serve uploaded files statically. Add new upload and category-seeding endpoints.

## Context
- .gsd/SPEC.md
- db_setup.sql
- routes.js
- server.js
- package.json

## Tasks

<task type="auto">
  <name>Update Database Schema and Install Multer</name>
  <files>db_setup.sql, server.js, package.json</files>
  <action>
    - Add a migration SQL comment block to `db_setup.sql` with:
      `ALTER TABLE Memes ADD meme_type VARCHAR2(10) DEFAULT 'image' CHECK (meme_type IN ('text','image','video'));`
      `ALTER TABLE Memes MODIFY image_url VARCHAR2(1000) NULL;`
      Also add more default categories: ('Funny', 'Funny memes'), ('Coding', 'Programming humor'), ('Gaming', 'Game related memes'), ('Sports', 'Sports memes').
    - Install `multer` via npm.
    - In `server.js`, add `express.static` to serve the `uploads/` directory.
    - Create `uploads/` directory if not existing.
  </action>
  <verify>grep -q "multer" package.json</verify>
  <done>Multer installed, uploads folder served statically, schema migration documented.</done>
</task>

<task type="auto">
  <name>Implement File Upload Endpoints</name>
  <files>routes.js</files>
  <action>
    - Configure multer with disk storage in routes.js, saving to `uploads/` with unique filenames.
    - Refactor `POST /api/memes` to accept multipart form data with optional file (images/videos).
    - Accept a `memeType` field ('text', 'image', 'video') from the request body.
    - For text memes, store description only (no file required).
    - For image/video memes, store the uploaded file path.
    - Return the created meme with its type and file path.
  </action>
  <verify>grep -q "multer" routes.js</verify>
  <done>POST /api/memes handles text, image, and video uploads with proper file storage.</done>
</task>

## Success Criteria
- [ ] Multer is installed and configured for file uploads.
- [ ] `uploads/` directory is served statically.
- [ ] POST /api/memes accepts multipart data with meme_type differentiation.
- [ ] Schema migration SQL is documented in db_setup.sql.
