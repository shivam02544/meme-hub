# Plan 3.2: Multi-Format Upload UI & Dashboard Update

## Objective
Update the frontend upload modal to support text, image, and video meme types. Update the meme card rendering to display each type correctly.

## Context
- .gsd/SPEC.md
- frontend/src/pages/Dashboard.jsx
- frontend/src/index.css

## Tasks

<task type="auto">
  <name>Update Upload Modal for Multi-Format</name>
  <files>frontend/src/pages/Dashboard.jsx</files>
  <action>
    - Add a meme type selector (text/image/video) to the upload modal.
    - When "text" is selected, hide the file input and show a large textarea for the meme text content.
    - When "image" or "video" is selected, show a file input accepting the relevant MIME types.
    - Submit the form as multipart/form-data using FormData when a file is attached.
    - For text memes, submit as JSON (no file).
  </action>
  <verify>grep -q "memeType" frontend/src/pages/Dashboard.jsx</verify>
  <done>Upload modal allows choosing text, image, or video type and handles submission correctly.</done>
</task>

<task type="auto">
  <name>Update Meme Card Rendering</name>
  <files>frontend/src/pages/Dashboard.jsx, frontend/src/index.css</files>
  <action>
    - In the meme grid, check `meme.memeType` (or `meme.meme_type`).
    - For 'image': render an `<img>` tag (existing behavior).
    - For 'video': render a `<video>` tag with controls.
    - For 'text': render the description/content in a styled text block (no image wrapper).
    - Add CSS for `.meme-text-content` for text-only meme cards.
  </action>
  <verify>grep -q "video" frontend/src/pages/Dashboard.jsx</verify>
  <done>Meme cards correctly render text, image, and video types with appropriate elements.</done>
</task>

## Success Criteria
- [ ] Upload modal supports text, image, and video meme creation.
- [ ] Meme cards render differently based on meme type.
- [ ] File uploads use FormData; text memes use JSON.
