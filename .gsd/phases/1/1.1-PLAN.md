# Plan 1.1: Global Styles & Skeuomorphic Tokens

## Objective
Establish the foundational CSS variables and global styles for the skeuomorphic design system, including soft shadows, subtle gradients, and base typography.

## Context
- .gsd/SPEC.md
- .gsd/ARCHITECTURE.md
- frontend/src/index.css
- frontend/src/App.css

## Tasks

<task type="auto">
  <name>Define CSS Variables for Skeuomorphic Design</name>
  <files>frontend/src/index.css</files>
  <action>
    - Add CSS variables in :root for primary, secondary backgrounds (e.g., off-white, soft gray).
    - Add variables for soft drop shadows (raised objects) and inset shadows (pressed states).
    - Add variables for subtle linear gradients to give a 3D feel to buttons and cards.
    - Avoid heavy, high-contrast shadows to keep it clean and modern.
  </action>
  <verify>grep -q "var(--" frontend/src/index.css</verify>
  <done>CSS variables exist for backgrounds, shadows, and gradients.</done>
</task>

<task type="auto">
  <name>Apply Base Body Styles</name>
  <files>frontend/src/index.css, frontend/src/App.css</files>
  <action>
    - Update body styling to use the new background variables.
    - Set up a readable, modern font stack if not present.
    - Clear out any default Vite styles that conflict with a clean layout.
  </action>
  <verify>grep -q "background-color" frontend/src/index.css</verify>
  <done>Body has a clean background color applied from the defined variables.</done>
</task>

## Success Criteria
- [ ] CSS variables for skeuomorphic design (shadows, gradients) are defined.
- [ ] Base typography and body backgrounds are set.
