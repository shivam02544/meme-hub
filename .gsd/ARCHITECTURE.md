1. User interacts with the React frontend forms and buttons.
2. Frontend sends HTTP requests via `axios` to backend endpoints (`/api/*`).
3. Express router (`routes.js`) handles requests, verifying JWTs for protected routes.
4. Express queries Oracle Database via `oracledb` pool.
