# Plan 2.2: Profile Edit Backend

## Objective
Implement backend routing and Oracle Database logic to handle user profile updates (e.g., updating their registered name).

## Context
- .gsd/SPEC.md
- routes.js
- db.js

## Tasks

<task type="auto">
  <name>Implement User Profile Update Endpoint</name>
  <files>routes.js</files>
  <action>
    - Add a `PUT /api/users/profile` endpoint, protected by the existing `authenticateToken` middleware.
    - Extract `name` (and any other profile fields) from `req.body` and user ID from `req.user.id`.
    - Execute SQL to update the user in the database (e.g., `UPDATE Users SET name = :name WHERE id = :id`).
    - Return a success response and the updated user mapping.
  </action>
  <verify>grep -q "/api/users/profile" routes.js</verify>
  <done>API successfully handles PUT requests to update user profiles in OracleDB.</done>
</task>
