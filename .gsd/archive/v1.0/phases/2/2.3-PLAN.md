# Plan 2.3: Profile Edit Frontend

## Objective
Build the frontend profile management page where users can view and edit their profile details using the new skeuomorphic design.

## Context
- .gsd/SPEC.md
- frontend/src/App.jsx
- frontend/src/components/Navbar.jsx

## Tasks

<task type="auto">
  <name>Build Profile Page Component</name>
  <files>frontend/src/pages/Profile.jsx</files>
  <action>
    - Create a new `Profile.jsx` matching the `.auth-card` or dashboard skeuomorphic style.
    - Fetch and display the current user details.
    - Include a simple edit form for updating their name, utilizing the `PUT /api/users/profile` backend route.
    - On success, update the client-side user session cache/state.
  </action>
  <verify>grep -q "Profile" frontend/src/pages/Profile.jsx</verify>
  <done>Profile page correctly accesses and submits edits to the backend.</done>
</task>

<task type="auto">
  <name>Wire Profile Page Routing</name>
  <files>frontend/src/App.jsx, frontend/src/components/Navbar.jsx</files>
  <action>
    - Add a route `/profile` in `App.jsx` pointing to `Profile.jsx`.
    - Update `Navbar.jsx` to make the User block a clickable link leading to `/profile`.
  </action>
  <verify>grep -q "/profile" frontend/src/App.jsx</verify>
  <done>The user can navigate to `/profile` from the Navbar and view the page.</done>
</task>

## Success Criteria
- [ ] Profile page exists and allows modifying details via form.
- [ ] Local session and Navbar update synchronously when the user's name is saved.
